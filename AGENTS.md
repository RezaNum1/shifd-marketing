# Shifd Marketing

## Required Reading

Before implementing any frontend feature, read:

1. /docs/PRD.md
2. /docs/IMPLEMENTATION_NOTES.md
3. /docs/DESIGN_RULES.md

Inspect the relevant Google Stitch references under:

/design-reference

Each reference folder may contain:

- screen.png — visual reference
- code.html — structural/styling reference

Do not copy Stitch HTML directly into production code.

## Design Interpretation

Google Stitch is the primary visual direction, but generated screens may contain
inconsistencies.

Follow /docs/DESIGN_RULES.md when resolving ambiguity.

Codex may make minor design improvements for consistency and usability.

Major workflow, navigation, information architecture, or product changes require
user approval.

Meaningful deviations from Stitch must be documented in:

/docs/DESIGN_DECISIONS.md
